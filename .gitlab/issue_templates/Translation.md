- [ ] Message keys and argument names such as `{value0}` and `{count}` are unchanged.
- [ ] Plural messages keep an `other` branch and include the forms this language needs.
- [ ] The file is valid UTF-8 JSON, without comments or trailing commas.

- [ ] I wrote this translation or have permission to contribute it.

No build or merge request is required. The maintainer will validate and integrate the translation.
